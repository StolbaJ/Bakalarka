# ski-database-bachelor-s-project
Web application for managing ski inventory with connection to service equipment.

# Czech description:
Cílem samostatného projektu a případné bakalářské práce je návrh a implementace webové aplikace pro evidenci a správu inventáře lyží s s napojením na servisní zařízení. Součástí řešení bude databáze lyží, kde každá položka bude označena unikátním QR/BAR kódem a unikátním číslem, umožňujícím rychlou identifikaci prostřednictvím webového rozhraní. Aplikace bude propojena se systémem, do něhož mohou přicházet objednávky na servis lyží. Po naskenování QR/BAR kódu, či opsáním číselného identifikátoru, se tak uživateli zobrazí konkrétní servisní úkoly pro daný pár lyží. Při zalogování zákazníkem, který vyplní číslo objednávky bude moci zákazník zjistit stav svých lyží. Zákazník může zjistit přibližnou čekací dobu na servis lyží. V grafickém rozhraní aplikace bude také možné si zobrazit různé grafy(např. průměrná doba servisu, nejčastější typy servisu) Další částí bude integrace s externím zařízením, který při servisu běžek generuje technologické parametry. Tyto údaje budou ukládány k příslušným lyžím v databázi, čímž vznikne komplexní systém pro správu inventáře, servisních požadavků i technologických dat.
